ARGO Avatar Motion Rig — Portrait Preview

The new 5-layer rig (avatar-motion.js) driving the real portrait art through the live, unmodified Portrait renderer (cortana-avatar.js).

Honest limit of this first pass: only the rig's aperture curve (open/close timing, attack/release, per-state onset) is being fed into the photo, exactly the way index.html already feeds its envelope value in. The six-viseme shape blend (open/wide/rounded/contact/closed) is real and visible in the meters below, but the portrait shader only exposes one continuous "mouth" scalar today - it does not yet warp differently per viseme. Making the photo's mouth actually change SHAPE (not just openness) needs calibrated per-viseme landmark work in cortana-avatar.js's shader, which is the "final art not started" item AGENTS.md flags. This page is safe to leave running: it only reads cortana-avatar.js, nothing about the live dashboard is touched.
